# FocusStudy 

**FocusStudy** — це легкий та зручний мобільний застосунок для тайм-менеджменту та оптимізації самостійного навчання, створений на основі техніки **Pomodoro**.

---

## Про проєкт
Головна мета застосунку — допомогти студентам та школярам подолати прокрастинацію, структурувати час підготовки до занять та фіксувати реальні витрати часу на кожну дисципліну без зайвого візуального й функціонального перевантаження.

* **Галузь:** Освіта
* **Цільова аудиторія:** Студенти, учні старших класів, самостійні розробники та всі, хто займається онлайн-навчанням.

---

## Основний механізм роботи
1. **Вибір дисципліни:** Користувач обирає навчальний предмет (за допомогою швидких кольорових тегів або ручного вводу).
2. **Цикл концентрації:** Запуск 25-хвилинного таймера для глибокої роботи без відволікань.
3. **Чергування відпочинку:** Автоматичний перехід на коротку перерву (5 хвилин) після завершення сесії та довгу (15–20 хвилин) після кожних 4 успішних циклів.
4. **Збереження даних:** Автоматична фіксація завершених навчальних інтервалів у локальне сховище для формування щоденної статистики.

---

## Основні функціональні вимоги
* **Керування таймером:** запуск, пауза та скидання сесій фокусу (25 хв) і перерв (5/15 хв).
* **Вибір дисципліни:** прив'язка сесії до предмета за допомогою кольорових тегів або ручного вводу.
* **Звукові та вібросигнали:** сповіщення про завершення інтервалу навчання чи відпочинку.
* **Налаштування часу:** зміна тривалості сесій фокусування та перерв під власний темп.
* **Облік щоденної статистики:** збереження кількості виконаних сесій і підрахунок загального часу навчання за день.
* **Трекінг стрику (Streak):** лічильник днів безперервного щоденного навчання.

## Архітектура та структура репозиторію (MVP)
- `backend/` — REST API сервер на Python (FastAPI, Pydantic, Google GenAI SDK).
- `mobile/` — нативний Android-застосунок на Kotlin (Jetpack Compose, Retrofit, OkHttp).

## Команди запуску

### 1. Запуск Backend (Python FastAPI)
1. Перейдіть у папку `backend/`, створіть та активуйте віртуальне середовище `venv`, встановіть залежності: `pip install -r requirements.txt`
2. Створіть файл `backend/.env` із параметром `GEMINI_API_KEY=ваш_ключ`
3. Запустіть сервер: `uvicorn main:app --host 0.0.0.0 --port 8000` (Swagger UI: `http://localhost:8000/docs`)

### 2. Запуск Mobile (Android Studio)
1. Відкрийте папку `mobile/` в Android Studio та дочекайтеся синхронізації Gradle.
2. Запустіть емулятор і прокиньте порт сервера: `adb reverse tcp:8000 tcp:8000`
3. Натисніть **Run (▶)**.

## Опис API та приклади AI-функції
- `GET /health` — перевірка стану сервера (`200 OK`, повертає `{"status": "ok", "service": "FocusStudy Backend"}`).
- `POST /api/plan` — приймає JSON `{"topic": "Назва теми", "available_minutes": 60}` і повертає структурований Pomodoro-план (`200 OK`) або помилку валідації (`422 Unprocessable Entity`). Використовує Google Gemini (`gemini-3.8-flash`) з резервним локальним генератором (*Graceful Fallback*).

## Обмеження поточної версії (MVP)
- Stateless-архітектура (історія згенерованих планів не зберігається у базі даних).
- Відсутня авторизація користувачів.
