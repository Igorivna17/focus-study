# Архітектурні та технічні рішення (ADR)

- **ADR-001: Використання FastAPI як проміжного бекенду замість прямого виклику Gemini з Android.**
  *Причина:* Захист `GEMINI_API_KEY` від декомпіляції APK-файлу та централізована валідація даних.
- **ADR-002: Застосування `adb reverse tcp:8000 tcp:8000` та `localhost` у Retrofit.**
  *Причина:* Стабільна локальна маршрутизація між емулятором Android та локальним сервером Windows незалежно від налаштувань брандмауера для `10.0.2.2`.
- **ADR-003: Збільшення таймаутів OkHttp до 60 секунд.**
  *Причина:* Генерація структурованої відповіді LLM займає більше часу, ніж стандартні 10 секунд таймауту OkHttp.
- **ADR-004: Реалізація Graceful Fallback у `POST /api/plan`.**
  *Причина:* Забезпечення стабільної роботи застосунку навіть при тимчасовій недоступності (`503`) серверів Google Gemini.
