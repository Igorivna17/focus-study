# Тестування та перевірка працездатності

## Запуск середовища для перевірки

1. **Запуск Backend (Python FastAPI):**
    cd backend
    .\venv\Scripts\activate
    uvicorn main:app --host 0.0.0.0 --port 8000

2. **Прокидання порту для Android Emulator:**
    adb reverse tcp:8000 tcp:8000

## Обов'язкові тестові сценарії

1. **Health Check:**
   Запит `GET http://localhost:8000/health` повертає HTTP `200 OK` та JSON-відповідь `{"status": "ok", "service": "FocusStudy Backend"}`.

2. **Успішна генерація плану (End-to-End):**
   Введення теми `"екзамен з математики"` та доступного часу `60` хвилин у мобільному застосунку -> сервер фіксує у логах `"POST /api/plan HTTP/1.1" 200 OK`, а в Android UI відображаються 2 картки Pomodoro-інтервалів та порада на перерву.

3. **Клієнтська валідація:**
   Спроба надіслати порожнє поле теми або рядок довжиною менше 3 символів -> у мобільному інтерфейсі відображається повідомлення про помилку валідації без виконання зайвого мережевого запиту.

4. **Серверна валідація:**
   Надсилання запиту `POST /api/plan` зі значенням `"available_minutes": 10` (поза діапазоном `25..300`) через Swagger UI (`/docs`) -> сервер повертає статус `422 Unprocessable Entity`.
