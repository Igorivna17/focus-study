# AI-компонент системи

## Призначення AI
Перетворення довільної навчальної теми та ліміту часу на структурований покроковий план самопідготовки за технікою Pomodoro українською мовою.

## Конфігурація та формат даних
- **SDK:** `google-genai` (`genai.Client`).
- **Модель:** `gemini-3.8-flash` (з відключеним thinking-бюджетом `thinking_budget=0` для мінімізації затримки).
- **Structured Outputs:** передається параметр `response_mime_type="application/json"` та `response_schema=PlanResponse`, що змушує модель повертати JSON, сумісний із Pydantic-моделлю.

## Обмеження та механізм Fallback
- Зовнішній API може повертати `503 UNAVAILABLE` під час пікових навантажень.
- У `backend/main.py` реалізовано 3 швидкі спроби запиту з таймаутом 15 секунд на спробу.
- Якщо всі 3 спроби невдалі, спрацьовує **Graceful Fallback**: бекенд детерміновано генерує валідний `PlanResponse` із шаблонів етапів навчання («Огляд теорії», «Практичне закріплення», «Повторення складних моментів»), гарантуючи безперебійну роботу мобільного клієнта (`200 OK`).
