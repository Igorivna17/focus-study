# AI-компонент системи

## Призначення AI
Перетворення довільної навчальної теми та ліміту часу на структурований покроковий план самопідготовки за технікою Pomodoro українською мовою.

## Конфігурація та формат даних
- **SDK:** `google-genai` (`genai.Client`).
- **Модель:** `gemini-3.8-flash` (з відключеним thinking-бюджетом `thinking_budget=0` для мінімізації затримки).
- **Structured Outputs:** передається параметр `response_mime_type="application/json"` та `response_schema=PlanResponse`, що змушує модель повертати JSON, сумісний із Pydantic-моделлю.

## Обмеження та механізм Fallback
- Зовнішній API може повертати `503 UNAVAILABLE` під час пікових навантажень.
- У `backend/main.py` реалізовано 3 швидкі спроби запиту з таймаутом 15 секунд на спробу.
- Якщо всі 3 спроби невдалі, спрацьовує **Graceful Fallback**: бекенд детерміновано генерує валідний `PlanResponse` із шаблонів етапів навчання («Огляд теорії», «Практичне закріплення», «Повторення складних моментів»), гарантуючи безперебійну роботу мобільного клієнта (`200 OK`).

## Розширення AI-компонента (v2.1.0 — Лабораторна робота №6, Варіант А)
Пайплайн обробки запиту розділено на три незалежні етапи:
1. **Підготовка та валідація даних (`backend/app/services/input_preparer.py :: prepare_plan_input`):**
   * очищення пробілів у `topic` та обрізання `study_context` до 500 символів;
   * виділення до 5 ключових термінів фокусу з контексту користувача;
   * детермінована евристична фільтрація непридатних запитів (відсутність змістовних літер, клавіатурний шум на кшталт `asdfghjkl` / `qwerty`, побутові доручення на кшталт `купити хліб`). Непридатні запити відхиляються до виклику LLM зі станом `is_suitable=false`.
2. **AI-обробка (`GeminiPlanProvider` / `MockPlanProvider`):**
   * інтеграція `study_context` у промпт моделі `gemini-3.8-flash` (або шаблонний генератор `MockPlanProvider`) з позначкою `context_applied=true`;
   * додаткова семантична перевірка придатності теми моделлю (`_GeminiPlanSchema.is_suitable`).
3. **Обробка результату та відображення (`PlanService` + Android UI):**
   * непридатні запити (`is_suitable=false`) не зберігаються в локальну історію пристрою, а відображаються окремою інформативною карткою з можливістю ввести іншу тему.
